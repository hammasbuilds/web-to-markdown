Retrying requests

By default fetchkit does not retry. Pass a Retry policy to the client to retry failed requests with exponential back-off.

from fetchkit import Client, Retry

client = Client(retry=Retry(total=5, backoff=0.5))
response = client.get("https://api.example/items")

Which failures are retried

Only idempotent methods are retried unless you opt in:

FailureRetriedNotes
Connection erroryesalways
HTTP 503yeshonours Retry-After
HTTP 500noset status_forcelist
Read timeoutGET onlyPOST is never retried

Back-off schedule

The delay before attempt n is backoff * 2 ** (n - 1) seconds:

  1. 0.5 seconds
  2. 1 second
  3. 2 seconds
    • capped by max_backoff
    • jitter is added when jitter=True

Warning

Retrying a non-idempotent request can duplicate side effects, such as a payment.

$ fetchkit get https://api.example/items --retries 3
